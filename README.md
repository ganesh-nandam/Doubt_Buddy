# Doubt-Buddy: Learn by Thinking
A Socratic AI tutor that guides students to the answer instead of handing it over, and gives teachers a live view of where the class is struggling.

🔗 Live Demo: doubt-buddy-nu.vercel.app   🔗 Backup link: Bolt-hosted version

# ❓ The Problem
Students get stuck, and when an AI simply gives the answer, they copy it without understanding.
Many students hesitate to ask questions in front of the class, so doubts pile up silently.
Teachers with 30+ students cannot see who is struggling with what until exam results arrive.

# 💡 The Solution
Doubt-Buddy has two connected sides:
1. For students: a Socratic tutor that asks guiding questions so the student reaches the answer themselves. It tracks doubts, finds weak spots and builds personalized practice.
2. For teachers: a live class dashboard that turns student doubts into insights: weak-topic heatmaps, a roster showing who needs help, and an auto-generated remediation worksheet.

A Student / Teacher switch at the top of the app moves between the two views.
